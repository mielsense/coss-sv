# Security policy

## Supported versions

COSS for Svelte has not published a stable release. Security fixes currently target the `main` branch.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/mielsense/coss-sv/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected component or route, reproduction steps, impact, environment, and any known
workaround. Remove tokens, personal data, and private application code from the report. Maintainers
will coordinate triage and disclosure through the private advisory.

General component bugs, visual differences, and accessibility problems can use the public issue templates unless they expose user data or create a security boundary failure.
