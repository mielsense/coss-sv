# Security policy

## Supported versions

COSS for Svelte has not published a stable release. Security fixes currently target the `main` branch.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for the `mielsense/coss-sv` repository. Do not open a public issue for a suspected vulnerability.

Include the affected component or route, reproduction steps, impact, and any known workaround. Maintainers will acknowledge the report through GitHub and coordinate disclosure there.

General component bugs, visual differences, and accessibility problems can use the public issue templates unless they expose user data or create a security boundary failure.
