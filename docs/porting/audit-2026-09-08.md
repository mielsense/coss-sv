# Port audit, September 8, 2026

This pass reviewed all 54 component families against the pinned, MIT-designated COSS registry,
checked the Shards behavior behind confirmed defects, reviewed the documentation, and repaired
reproduced regressions. Astra agents at medium reasoning handled independent implementation
and review lanes. Changes were integrated only after separate parity/accessibility and Svelte
reviews of the exact lane commits.

This audit does not establish complete behavioral parity. One reproduced adapter limitation
remains unresolved: Number Field serialization inside a named Field. Its evidence and supported example workaround
are below.

## Repairs

- Combobox renders initial selected labels in SSR and the browser, and updates them after external
  selection and item-label changes. Independent input control, popup search, multiple selection,
  canceled edits, IME composition, and server-to-client hydration remain covered.
- Select preserves the selected object's identity when different options share a label.
- Checkbox, Switch, Toggle, Radio Group, Tabs, Toggle Group, Select, and Combobox observe bindings
  that begin as `undefined` and receive a value later. Existing cancellation and default-state
  behavior remains covered. Checkbox Group's public binding type now accepts its supported initial
  `undefined` state.
- Calendar toggles selections using the same timezone-normalized dates used to display them.
- Number Field restores accepted text after a canceled edit and synchronizes native form resets.
- OTP preserves its bound value, displayed slots, and submitted value when a form reset is canceled.
- Command's Input, List, Panel, Footer, and Shortcut, plus Menu and Context Menu submenus, forward
  element references and clear them on teardown.
- Documentation previews retain user state when switching between Preview and Code. Hidden
  examples cannot receive focus.
- The documentation preprocessor recognizes exact Svelte script openings and quoted multiline
  attributes, without treating custom elements as scripts or repeatedly scanning blank lines.
- Standalone previews no longer load the site's analytics script on a fresh page load.
- Installation, Slider composition, component prop descriptions, and OTP labeling guidance now
  describe the actual Svelte APIs.
- The Number Field form example submits one canonical numeric value and retains native Enter
  submission by placing its name on Number Field rather than the surrounding Field.

## Remaining limitations

**Number Field inside a named Field:** Shards assigns the inherited name to the formatted
display input, while Number Field assigns it to the canonical numeric input. A `FormData`
object therefore contains two entries, which can differ under localized formatting. A proposed
form-disassociation workaround was rejected because it breaks native Enter submission.
The shipped form example now uses an unnamed Field and names Number Field directly. Consumers
that need Field's name-based server-error association still need the underlying primitive repair.
See [Number Field evidence](components/number-field.md).

## Security and dependency status

The source patterns behind all nine attached CodeQL alerts were rewritten, with regressions for
the preprocessor and source-display boundaries. Seven alerts were in test assertions, one in the
build-time parity inventory, and one in the documentation preprocessor. No runtime XML parser or
XML upload handler was found. Added tests cover script/SVG markup, XML entity syntax, unsafe
registry names and remote dependencies, and source size limits. The installed dependency audit
reported zero advisories.

GitHub alerts remain open until a new CodeQL scan runs; no local CodeQL executable was available.
The dependency PRs were inspected through their actual CI logs. Their first failures and current
main's relevant fixes are recorded in the security report. No PR was merged or modified.
